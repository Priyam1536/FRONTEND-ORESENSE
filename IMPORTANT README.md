# OreSense AI - Frontend
his is the **frontend interface** for OreSense AI, a modern web application designed to provide a seamless and intuitive user experience for analyzing and managing LCA (Life Cycle Assessment) data.
## 🚀 Features
- Responsive and modern UI built with React
- Clean component structure for scalability
- Integration-ready with OreSense AI backend
- Easy customization and extension
